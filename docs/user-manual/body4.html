8.การแก้ไขปัญหาเบื้องต้น

อาการสาเหตุที่เป็นไปได้และวิธีแก้ไข
ค้นหาแล้วไม่พบเลข VIN 1) เลือกลานไม่ถูกต้อง — ตรวจสอบชื่อลานที่แถบด้านบน
2) รถยังไม่ถูกนำเข้าระบบ — ประสานผู้ดูแลระบบให้นำเข้าไฟล์
3) พิมพ์เลขไม่ครบ — ลองพิมพ์ให้ยาวขึ้น
ระบบแจ้ง "รถยังไม่ Gate-in" ทั้งที่รถอยู่ในลาน ข้อมูลรถยังโหลดไม่เสร็จในครั้งแรก ให้รอสักครู่แล้วค้นหาใหม่อีกครั้ง หากยังพบปัญหา ให้ตรวจสอบ Car Status ของรถที่หน้ารายการรถ
กล้องสแกนไม่ทำงาน ตรวจสอบว่าอนุญาตให้เว็บไซต์ใช้กล้องแล้วหรือไม่ ที่ตั้งค่าของอุปกรณ์ และปิดแอปอื่นที่ใช้กล้องอยู่
ภาพถ่ายไม่ปรากฏบนเครื่องอื่น รอให้การอัปโหลดเสร็จสมบูรณ์ก่อนปิดหน้าจอ และตรวจสอบสัญญาณอินเทอร์เน็ต หากเพิ่งบันทึก ให้รอประมาณ 1 นาทีแล้วรีเฟรช
ตัวเลขในคิวงานไม่ตรงกับที่ปฏิบัติจริง ตรวจสอบว่าบันทึกผลครบทุกคันแล้ว รถที่ตรวจแล้วแต่ยังไม่ได้นำกลับไปจอด จะยังคงแสดงในรายการจนกว่าพนักงานขับรถจะยืนยันตำแหน่งจอดใหม่
Gate-out ไม่ได้ ระบบแจ้งไม่มีคิวงาน รถคันนั้นไม่อยู่ในคิวงานส่งมอบ ให้ประสานผู้ดูแลระบบเพื่อสร้างคิวงานหรือเพิ่มรถเข้าคิวที่หน้า Operation ก่อน
คิวงานที่สร้างไว้ไม่ปรากฏที่สถานี ตรวจสอบว่าเลือกประเภทงานถูกต้อง คิวงานแต่ละประเภทปรากฏเฉพาะที่สถานีของตนเท่านั้น และตรวจสอบว่าสร้างคิวในลานเดียวกับที่พนักงานเลือกใช้งาน
ระบบให้เข้าสู่ระบบใหม่ระหว่างวัน บัญชีหมดอายุตามรอบเที่ยงคืน หรือผู้ดูแลระบบปรับสิทธิ์บัญชี ให้เข้าสู่ระบบใหม่ตามปกติ
หน้าจอไม่แสดงฟังก์ชันใหม่ ปิดแอปแล้วเปิดใหม่ หากยังไม่อัปเดต ให้รีเฟรชแบบล้างแคชตามข้อ 3.6

9.แนวปฏิบัติในการใช้งาน

9.1ข้อกำหนดด้านความถูกต้องของข้อมูล

  1. บันทึกข้อมูลทันทีที่ปฏิบัติงานเสร็จ ณ จุดปฏิบัติงาน ห้ามรวบรวมบันทึกย้อนหลัง เนื่องจากระบบบันทึกวันเวลาจริงเป็นหลักฐาน
  2. ถ่ายภาพความเสียหายให้เห็นทั้งตำแหน่งโดยรวมและรายละเอียดของจุดที่เสียหาย
  3. ตรวจสอบเลข VIN ให้ตรงกับตัวรถทุกครั้งก่อนกดยืนยัน
  4. ตรวจสอบลานที่เลือกก่อนเริ่มปฏิบัติงานทุกครั้ง

9.2ข้อกำหนดด้านความปลอดภัยของบัญชี

  1. ห้ามเปิดเผยรหัสผ่านหรือใช้บัญชีร่วมกับผู้อื่น
  2. ออกจากระบบทุกครั้งเมื่อใช้อุปกรณ์ร่วมกับผู้อื่น
  3. แจ้งผู้ดูแลระบบทันทีเมื่ออุปกรณ์สูญหายหรือสงสัยว่ามีผู้อื่นเข้าถึงบัญชี

9.3ข้อกำหนดสำหรับผู้ดูแลระบบ

  1. ตรวจสอบความถูกต้องของไฟล์ก่อนนำเข้าทุกครั้ง และออกรายงานเก็บไว้ก่อนดำเนินการที่มีผลถาวร
  2. ปิดใช้งานบัญชีของพนักงานที่พ้นสภาพทันที
  3. ตั้งชื่อคิวงานให้สื่อความหมายและสอดคล้องกับเอกสารการทำงาน
  4. ตรวจสอบความสอดคล้องของยอดรถในลานกับการตรวจนับจริงอย่างสม่ำเสมอ
