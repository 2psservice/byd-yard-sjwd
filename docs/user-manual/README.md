ไฟล์ในโฟลเดอร์นี้คือต้นฉบับของ [`docs/SJWD-Yard-Control-User-Manual.pdf`](../SJWD-Yard-Control-User-Manual.pdf)
(เอกสารเลขที่ 2PS-SJWD-UM-001) แก้ไขเนื้อหาที่ไฟล์ `body*.html` แล้วสร้าง PDF ใหม่

| ไฟล์ | เนื้อหา |
| --- | --- |

## การสร้างเอกสารใหม่

ต้องมี Playwright/Chromium, `pypdf` และฟอนต์ไทย (แพ็กเกจ `fonts-thai-tlwg`)

```bash
cd docs/user-manual
python3 build.py          # → SJWD-Yard-Control-User-Manual.pdf
```

`build.py` เรนเดอร์สองรอบ รอบแรกใส่เครื่องหมายซ่อนไว้ในหัวข้อเพื่ออ่านว่าแต่ละ
หัวข้ออยู่หน้าไหน แล้วรอบที่สองใส่เลขหน้าจริงลงสารบัญและตัดเครื่องหมายออก
(ข้อความไทยดึงกลับจาก PDF ได้ไม่แน่นอน จึงใช้เครื่องหมายเป็นอักษรอังกฤษแทน)

เมื่อสร้างเสร็จให้คัดลอกไฟล์ PDF ไปไว้ที่ `docs/` และปรับ **ฉบับแก้ไขครั้งที่**
กับ **วันที่มีผลบังคับใช้** ใน `build.py` พร้อมเพิ่มบรรทัดในตารางประวัติการแก้ไข
